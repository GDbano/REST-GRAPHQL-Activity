Student Portal Demo

REST API + GraphQL demo for student management

Quick start

Run npm start, then open this page or use the API endpoints below.

GraphQL IDE: /graphql

REST API

GET /api/students
GET /api/students/:id
POST /api/students
PUT /api/students/:id
PATCH /api/students/:id
DELETE /api/students/:id

GraphQL example

query {
  students { id name email major year }
}
mutation {
  addStudent(input: { name: "Lina", email: "lina@example.com", major: "Biology", year: 2 }) {
    id
    name
}
}

Testing instructions

Run npm start and open http://localhost:3000 to use this portal.

Use the following API tools to test endpoints:

  • Browser or curl for REST: GET /api/students
  • GraphQL IDE: /graphql
